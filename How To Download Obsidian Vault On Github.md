1. Open your browser and navigate to the **main page of the repository** you want to download.
2. Click the green **Code** button located above the file list. 
3. Select **Open with GitHub Desktop** from the dropdown menu. 
4.  Your browser will prompt you to open the application. Click **Open GitHub Desktop**.
5.  Inside the app, click **Choose...** to pick the local folder on your computer where you want the repository saved. 
6.  Click Clone
