___
>## The Algorithm
>*Gargantuan Construct (Epic Boss)*
>___
>- **Armor Class** 25
>- **Hit Points** 305 (15d20 + 150) plus 300 (15d20 + 150) per player character
>- **Speed** 30 ft.
>- **Initiative** +12 (22)
>___
>|STR|DEX|CON|INT|WIS|CHA|
>|:---:|:---:|:---:|:---:|:---:|:---:|
>|30 (+10)|15 (+2)|30 (+10)|30 (+10)|20 (+5)|10 (+0)|
>___
>- **Saving Throws** Dex +11, Con +19, Int +19, Cha +9
>- **Skills** History +19, Insight +14, Intimidation +9, Perception +23
>- **Immunities** Cold, Fire, Lightning, Necrotic, Poison, Psychic; Blinded, Charmed, Deafened, Exhaustion, Frightened, Paralyzed, Petrified, Poisoned, Stunned
>- **Senses** Truesight 250 ft., Passive Perception 33
>- **Languages** All
>- **Challenge** 30 (XP 155,000; PB +9)
>- **Proficiency Bonus** +9
>___
>***Electronic Data Network.*** A creature that starts its turn within 60 feet of the Algorithm takes 21 (6d6) Lightning damage.  
>
>***Immutable Form.*** The Algorithm is immune to any spell or effect that would alter its form.  
>
>***Predictive Analytics.*** At the end of each of the Algorithm's turns, it rolls 1d20 for each player character fighting it. The Algorithm can replace any D20 Test made by it or a creature it can see with one of these predictive rolls. It must choose to do so before the roll, and it can replace a roll in this way only once per turn.  
>Each predictive roll can be used only once. Any unused predictive rolls are lost at the start of the Algorithm's next turn.  
>
>### Actions
>***Spellcasting (1/Round).*** The Algorithm casts one of the following spells, requiring no Material components and using Intelligence as the spellcasting ability (spell save DC 27):  
>
>At will: *Dispel Magic*, *Fabricate*  
>3/day each: *Scrying*, *Sending*, *Wall of Force*  
>1/day each: *Antimagic Field*, *Prismatic Wall*, *Reverse Gravity*  
>1/year: *Wish*  
>
>***The Algorithm always takes its turn on Initiative count 20.*** On its turn, the Algorithm can use its movement and interaction as normal. However, it does not take an action or Bonus Action on its turn unless forced to do so by a spell or other effect. Instead, the Algorithm takes one of the following Epic Actions at the end of each player character's turn:  
>- **Wire.** *Dexterity Saving Throw:* DC 26, one creature the Algorithm can see within 60 feet. *Failure:* 21 (2d10 + 10) Force damage, and if the target is a Huge or smaller creature, it has the Grappled condition (escape DC 20). The Algorithm can grapple up to six creatures at a time.
>- **Algorithmic Manipulation.** *Strength Saving Throw:* DC 26, one Huge or smaller creature or object the Algorithm can see within 120 feet. *Failure:* The Algorithm moves the target up to 30 feet in any direction, and the target has the Restrained condition. If the Algorithm lifts the target into the air, it is suspended there. The target remains held until the Algorithm releases it (no action required), uses this Epic Action again, or has the Incapacitated condition.
>- **Deatomization.** *Constitution Saving Throw:* DC 26, one creature or object the Algorithm can see within 300 feet. *Failure:* 65 (10d12) Necrotic damage. If this damage reduces the target to 0 Hit Points, it dies and its body is reduced to atoms. *Failure:* Half damage.
>
>***Reprogram (1/Round).*** *Intelligence Saving Throw:* DC 26, one creature Grappled by the algorithm. *Failure:* 55 (10d10) Piercing damage. If this damage reduces the target to 0 Hit Points, it dies and its brain is replaced with mechanical components. The target reanimates at the start of its next turn as a Construct under the Algorithm's control. It resembles the original creature, but its eyes glow with synthetic green light, and its body is covered in protruding wires, metal scraps, and glowing tubes.  
>
>***Assuming Direct Control (1/Round).*** The Algorithm targets a Construct within 120 feet and immediately enters and takes control of it. The Algorithm can still use its Epic Actions as normal and replaces the Construct's game statistics with its own, except the Construct's Hit Points. When the Construct is reduced to 0 Hit Points, the Algorithm reemerges in an unoccupied space within 15 feet of it.  
>
>***Epic Resistance.*** The Algorithm chooses one condition, spell, or other effect currently affecting them and rolls 1d20. On an 11+, the effect ends on it. The Algorithm can use this action even if it would otherwise be unable to take actions, its actions are being controlled by another creature, or if a spell or effect alters its game statistics.
