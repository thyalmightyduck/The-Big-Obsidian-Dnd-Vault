#### Feather Token

Generic Variant

---

You can use a Magic action to throw this black token into the air. You can see and hear through the token for one hour. The token disappears afterwards or if the distance between you and it exceeds 1 mile. The bird has the statistics of a **Raven**.

Multiple variations of this item exist, as listed below:

- *Feather Token (Raven)*
- *Feather Token (Snowy Owl)*
